---
name: security-review
description: Review requested code changes for exploitable security flaws and verify scoped mitigations.
---

围绕用户指定代码和真实入口画出信任边界：谁控制输入、以谁的权限执行、能访问什么资源。安全审查针对可达风险，不把普通开发扩成无关的全面整改。

- 追踪输入到敏感操作，检查身份与对象级授权、查询参数化、路径约束、命令拼接和输出编码。文件访问考虑规范化后的路径与符号链接；网络访问检查实际重定向和目标限制。
- 对凭据、会话和私密数据检查日志、返回值及存储边界；仅指出位置与泄露路径，不在报告中复述密钥。依赖问题依据当前可获得的版本与通告，无法核实时标明。
- 发现项给出入口、必要条件、影响和代码证据；区分已确认漏洞与待验证假设，避免仅凭危险函数名判定可利用。
- 在原约束层实施最小修复，使用无破坏性的本地用例验证攻击输入受阻且合法行为保留。未经授权不探测外部目标或执行真实攻击。
