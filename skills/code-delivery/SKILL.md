name: code-delivery
description: Implement a requested feature or code change with repository conventions, compatible interfaces, and focused verification.
---

先定位请求对应的入口、调用方、现有约定与验收条件；只读取能解释这条执行路径的文件。沿用项目已有依赖、构建方式和错误处理，新增抽象应有当前调用场景。

- 修改接口时同时检查调用方、类型、校验器与序列化格式。数据库变更考虑旧数据和迁移顺序；不要以类型断言掩盖运行时不匹配。
- 处理等待、失败、空数据与取消等相关状态，避免只实现成功路径。异步副作用检查重复提交和生命周期；涉及文件操作时使用明确路径。
- 完成必要的实现与集成，按改动风险运行最小但有效的检查。新增行为验证结果，修复问题补充能复现旧故障的回归验证。
- 交付时说明实际行为变化、验证结果与尚未验证的边界。工具未运行或失败时如实标明，不把计划当成已完成。
