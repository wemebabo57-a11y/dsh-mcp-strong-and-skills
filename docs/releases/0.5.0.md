0.5.0 移除了 0.4.0 引入的 `strong_bash` 及其 `bashTool` 开关，恢复 4 个默认工具入口。

### 为什么移除

- DeepSeek Harness 本身已经提供原生命令执行与文件修改能力：Windows 使用原生 `pwsh` 工具，POSIX 使用原生 `bash`，文件读写工具也始终可用。开启插件的 `strong_bash` 并不会授予这些能力。
- `strong_bash` 也不是“把默认 shell 改成 Bash”的开关。它是在原生工具之外额外注册的命令工具；在 Windows 上实际调用 `cmd.exe`，并不是 Bash。
- 这个额外通道直接以当前用户权限运行，不经过 DSH 原生的沙箱与审批流程。原提示把它描述成“开启后才能执行命令和修改文件”，既误导，也掩盖了真正的风险边界。

### 本次变更

- 删除 `src/bash-tool.mjs`、`strong_bash` 工具、`bashTool` 设置项与设置页开关。
- 删除 CLI `--bash on|off`、MCP 工具暴露、原生 Config 字段及相关文档与测试。
- 旧 profile 中残留的 `bashTool` 会被接受但忽略，避免升级后配置加载失败；不会再注册或执行任何 Bash 工具。
- 默认工具面恢复为 4 个。0.3.1 的项目设定与知识库、0.3.0 的引导与无限模式继续保留。

### 安装与升级

桌面端进入「插件 → 添加插件」，使用下面的固定版本来源，安装完成后完全退出并重新打开 DSH：

```text
github:wemebabo57-a11y/dsh-mcp-strong-and-skills#0.5.0
```

web profile 可在终端安装：

```sh
dsh plugin --profile web add github:wemebabo57-a11y/dsh-mcp-strong-and-skills#0.5.0
dsh --profile web
```

需要 Node.js 24.9+；原生插件兼容 DSH `>=0.2.1-rc.3 <0.3.0`。附带 `dsh-strong-skills-0.5.0.tgz` 安装包和 SHA-256 校验文件。
