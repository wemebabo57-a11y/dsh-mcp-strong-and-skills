0.3.1 为 Strong Skills 加入项目知识库与持久项目设定，让项目约定跨会话复用，让参考资料按任务需要进入上下文。

### 本次更新

- **本地与 GitHub 知识来源**：支持本地目录、单个文本文件和公开 GitHub 仓库，可指定分支或提交。
- **公共库与项目专属库**：按当前工作目录自动匹配项目，同时检索该项目的专属库与公共库；嵌套项目优先匹配最长根目录。
- **持久项目卡片**：保存最多 1200 字的技术栈、目录、编码约定和检查命令，新会话自动获得对应摘要，减少重复入门扫描。
- **按需控制上下文**：先列简短目录，再检索关键词、读取行片段，返回库 ID、路径和行号。知识结果单次最多 6000 字符，包括无限模式；工具入口仍为四个。
- **设置与 MCP 接通**：专用设置页支持来源和项目的增删改，CLI/MCP 可通过 `--knowledge-file` 接入。保留 0.3.0 的全部模式。

### 如何使用

打开「设置 → Strong Skills 编程增强 → 项目设定与知识库」，先添加项目并填写绝对根目录和项目卡片，再导入资料来源并选择公共或项目范围。

项目卡片由用户维护；源码和约定改变后请更新卡片。导入保存的是来源登记，正文首次检索时才读取。GitHub 当前支持公开仓库，私有仓库可先克隆到本地后导入。

### 安装与升级

桌面端进入「插件 → 添加插件」，使用下面的固定版本来源，安装完成后完全退出并重新打开 DSH：

```text
github:wemebabo57-a11y/dsh-mcp-strong-and-skills#0.3.1
```

web profile 可在终端安装：

```sh
dsh plugin --profile web add github:wemebabo57-a11y/dsh-mcp-strong-and-skills#0.3.1
dsh --profile web
```

需要 Node.js 24.9+；原生插件兼容 DSH `>=0.2.1-rc.3 <0.3.0`。附带 `dsh-strong-skills-0.3.1.tgz` 安装包和 SHA-256 校验文件。
