# Strong Skills 0.4.1 维护版

> 不新增常驻工具，集中修复安全、并发、路径与预算问题，并进一步降低常驻提示词占用。默认仍是 6 个入口，附加 Shell 后 7 个。

0.4.1 是 0.4.0 之后的维护版本。工具面、默认开关和 0.4.0 的功能集合保持不变，重点处理跨项目状态、不可信网络与路径输入、浏览器生命周期竞态，以及重复的参数校验和输出预算实现。

### 安全与稳定性

- **`strong_web` 缓存隔离**：搜索缓存与 `r1…rN` 别名按项目根隔离，只解析该项目最近一次搜索；根缓存增加 TTL 与 LRU 上限，避免跨项目读取旧结果和无限增长。
- **`strong_web` SSRF 防护**：默认拒绝 localhost、回环、私有、链路本地与云元数据地址；手动跟随重定向时逐跳复查，并提供 `webAllowPrivate` 显式开关。响应改为流式读取，在 2 MB 上限处中止，并按响应头/meta 解码字符集；实体解码不会因非法码点抛错。
- **非 ASCII diff 路径**：`strong_review` 与 `strong_context diff` 使用 `core.quotePath=false`，并兼容 Git 的 C 引号八进制文件名，中文、空格与特殊字符路径不再遗漏。
- **`strong_browse` 生命周期**：并发打开同一项目复用同一个启动 Promise；启动超时或失败会杀掉子进程并清理临时 profile；关闭动作排入会话队列；截图改为会话内独立目录与递增文件名，关闭时随 profile 清理；`type` 改用 CDP `Input.insertText`，补充 PageUp/PageDown/Home/End/Delete，修正 `scroll y=0` 与 `wait` 的实际等待时间。
- **Shell 与 MCP**：Shell 后端探测按平台/后端/路径/WSL 发行版/PATH 缓存；内置 Shell 的路径检查加入 realpath 校验，阻止目录链接逃逸，并新增 `sort`、`uniq`、`tr`、`cut`；MCP 输入改为分块收集后一次拼接，避免大帧的二次复杂度。

### 工具与体验优化

- **工作区与代码工具**：新增无内容的 `list`/采样清单，`map`、代码 inventory 与 `strong_review` 不再为每个文件读取完整正文；统一 `fitResult` 输出预算，避免多次 JSON 序列化；`diff` 支持 `unstaged|staged|all`，`search` 支持 `literal|terms` 与 `caseSensitive`；符号扫描补充类/对象方法，截断提示按实际资源档位生成。
- **校验与策略**：引擎、代码工具与 Shell 共用同一套参数校验，覆盖 number/boolean/minLength 等类型与范围；浏览提示只在工具实际注册时出现，视觉能力缓存增加 TTL 与有界淘汰。
- **知识库**：本地检索与 GitHub 一样按全部词匹配，本地扫描上限继承配置，项目设定解析增加记忆化。
- **技能与 CLI**：技能加载返回 `appliedLimit` 与 `limitReason`，不再静默截断；CLI 新增 `--version`/`-v`/`version`、`--flag=value` 与 `--web-private on|off`。

### 上下文预算

以下为 `node bin/strong.mjs budget` 的字符启发式估算，不是 tokenizer 或账单测量：

| 配置 | 常驻工具 | 估算 tokens |
| --- | ---: | ---: |
| 扩展工具 + 均衡增强（默认） | 6 | 1,473 |
| 扩展工具 + 附加 Shell | 7 | 1,798 |
| 精简工具 + 关闭增强思考 | 2 | 562 |
| 精简工具 + 附加 Shell + 关闭增强思考 | 3 | 886 |

普通模式不预载技能正文；只有 `strong_skill` 被调用时才读取。联网与浏览器工具只在模型实际调用时访问网络。

### 安装与升级

桌面端在「插件 → 添加插件」使用固定版本来源，安装后完全退出并重新打开 DSH：

```text
github:wemebabo57-a11y/dsh-mcp-strong-and-skills#0.4.1
```

web profile 在终端安装：

```sh
dsh plugin --profile web add github:wemebabo57-a11y/dsh-mcp-strong-and-skills#0.4.1
dsh --profile web
```

需要 **Node.js 24.9+** 与 **DSH 0.2.1-rc.3 或同一兼容范围内的更新版本**。
