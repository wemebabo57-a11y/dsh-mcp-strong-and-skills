# Strong Skills 0.4.4-preview.2 预览版

> 0.4.4-preview.2 修复另一轮黑盒实测发现的 13 个问题：恢复 `run_code` 里 strong_* 的参数类型，修正 `strong_web` 的 `open` 描述，让 `strong_code` 支持 Unicode 标识符并解释 diagnostics 排除项，让工作区 diff 覆盖嵌套仓库，补齐 `strong_browse` 的组合键、可见元素与 index 选择、焦点输入、轻量 mouse 返回与 close 状态。

0.4.4-preview.2 是 0.4.4 线的第二个预览版，工具面、开关与配置字段不变，升级不需要迁移 profile。默认 6 个入口的常驻预算为 **1,491** tokens（0.4.4-preview.1 为 1,477）。

### PTC 类型恢复

DSH 的 PTC 类型生成器只接受 `type/oneOf/properties/required/additionalProperties/items/enum/const` 与 `description/title/default/examples`；schema 里出现 `minLength/maxLength/minimum/maximum` 等键时，整棵 schema 会降级为 `unknown`，这正是 run_code 里 strong_* 参数全是 unknown 的原因。

现在注册前用 `portableSchema()` 生成可移植副本：保留全部参数名，只保留上述关键字，`enum/const/default/examples` 按数据原样复制。插件内部仍用完整 schema 校验，下限/上限/长度限制照常生效，宿主只是不再看见这些键。

### 行为修复

- **strong_web**：`open` 描述改为 `target`（搜索结果 id，如 `r1`）或完整网址，并写明 `maxChars` 500–20000。
- **strong_code**：symbols 的声明正则支持 Unicode 标识符（`计算`、`列表` 与 `Beta` 一样被识别）；diagnostics 必须传编译器/ESLint/测试原始输出，缺 text 的报错说明原因；排除项新增 `excludedReasons` 计数与 `excludedItems` 前 10 条，覆盖工作区外、密钥、符号链接与不可读路径。
- **strong_review / 工作区 diff**：diff 先探测所选路径所在的仓库。所选路径位于工作区内的嵌套仓库时，在仓库顶层运行 Git 并把名单映射回工作区相对路径；工作区根仍在同一仓库内时继续从根运行，路径口径不变。
- **strong_browse**：`press` 支持组合键（Ctrl/Alt/Shift/Meta，如 `Ctrl+A`、`Ctrl+Enter`）；selector/文字命中多个元素时优先可见元素，`index`（1 起始）选第几个；文字定位覆盖 li/div/span/p/标题与 role=menuitem/option/tab 等；`type` 无 selector 时写入当前焦点输入框；`mouse` 坐标点击只返回点击点与提示，不再附整页正文；`close` 之后的动作报 `BROWSER_NOT_OPEN`，需要重新 `open`。

### 验证

- `node --test`：**459 项全部通过**。
- `node scripts/check.mjs` 与 `node scripts/build-ui.mjs --check` 通过。
- 真实 Edge 无头浏览器探针（`scripts/probe-preview2.mjs`）：隐藏重复输入框场景下点击到可见元素、按文字点中 `role=menuitem` 的 div、无 selector 输入进焦点、`Ctrl+A` 后重输替换、`index: 2` 选中第二个按钮、`mouse` 不返回正文、`close` 后快照报 `BROWSER_NOT_OPEN`。
- Windows 测试临时目录清理改用 `maxRetries/retryDelay`，消除 EBUSY 竞态导致的稳定挂起。

### 已知边界

组合键依赖 Chromium 的按键处理，平台级快捷键（如 `Alt+F4`）不会生效；`index` 只在可见匹配里计数，超出范围按“没找到目标元素”报错；嵌套仓库 diff 的路径以工作区相对名返回，仓库顶层之外的变更被跳过。
