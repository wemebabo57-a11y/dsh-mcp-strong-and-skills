0.6.0 把 0.4.0、0.5.0 两次撤回的尝试合并成真正可选的 Shell 工具：默认仍然轻量，开启后可以选择 Git Bash、WSL、POSIX Bash、PowerShell 7 或 cmd。它不是替换 DSH 默认 shell 的开关，也不会改变 DSH 原生命令与文件工具。

### 为什么重新开发

0.4.0 的 `strong_bash` 在 Windows 上实际通过 `cmd.exe` 运行，既不是 Bash，也没有提供 shell 选择；0.5.0 因此直接移除了它，但这又丢掉了用户真正需要的 Bash 工作流。0.6.0 改为由插件自己解析并直接启动选定的可执行文件（`shell:false`），不再把命令交给 `cmd.exe` 拼接，同时把是否启用、使用哪个后端交给用户决定。0.4.0 与 0.5.0 的发行版和标签已删除，本版是替代版本。

### 本次更新

- **可选 `strong_shell`**：设置项 `shellTool` 默认关闭。关闭时不注册、不列出、不可调用，默认工具面仍是原来的 4 个；开启后为第 5 个工具。
- **多后端选择**：`auto`、`git-bash`、`wsl`、`bash`、`pwsh`、`cmd`。Windows 的 `auto` 依次尝试 Git Bash、WSL、PowerShell 7、`ComSpec`；POSIX 的 `auto` 使用 Bash。可用 `shellPath` 指定绝对可执行文件，用 `wslDistro` 指定 WSL 发行版。
- **真正的 Bash 语义**：Git Bash 与 WSL 都以 `bash --noprofile --norc -c <command>` 非交互执行；PowerShell 7 使用 `-NoLogo -NoProfile -NonInteractive -Command`，cmd 使用 `/d /s /c`。
- **有界执行**：工作目录从项目根目录或经校验的相对 `cwd` 开始，拒绝绝对路径、父目录穿越、符号链接/联接点逃逸；只传入允许列表中的非敏感环境变量；不读取 stdin；stdout/stderr 各限制 64 KiB；默认超时 60 秒（1–120 秒可调），超时或取消会终止整个进程树。
- **全链路接线**：设置页、原生 Config、CLI `--shell on|off`、`--shell-backend`、`--shell-path`、`--wsl-distro`、生成的 native/MCP patch 和独立 MCP 服务共用同一配置。MCP 将 `strong_shell` 标记为非只读、可破坏、非幂等、开放世界。
- **旧配置兼容**：旧 profile 的 `bashTool` 在未显式设置 `shellTool` 时迁移为新的开关；显式 `shellTool` 优先。

### 边界与安全

`strong_shell` 是额外的命令通道，不是 DSH 原生沙箱的一部分。命令以当前用户权限运行，可以访问项目外的文件，也不经过 DSH 原生审批。设置页只会在开启时显示这条风险提示。请只在可信项目中开启，并优先使用最小权限账户。

### 如何使用

设置页打开「附加 Shell 工具」，选择后端；Git Bash 需要先安装 Git for Windows，WSL 需要先安装并配置发行版。下一次请求即可看到 `strong_shell`；关闭开关后工具立即从发现与执行中移除。

MCP 用户可在启动命令追加：

```sh
node bin/strong.mjs serve --root /absolute/path/to/project --shell on --shell-backend git-bash
```

也可先查看将写入 MCP 配置的参数：

```sh
node bin/strong.mjs config --mode mcp --root . --shell on --shell-backend git-bash
```

### 安装与升级

桌面端进入「插件 → 添加插件」，使用下面的固定版本来源，安装完成后完全退出并重新打开 DSH：

```text
github:wemebabo57-a11y/dsh-mcp-strong-and-skills#0.6.0
```

web profile 可在终端安装：

```sh
dsh plugin --profile web add github:wemebabo57-a11y/dsh-mcp-strong-and-skills#0.6.0
dsh --profile web
```

需要 Node.js 24.9+；原生插件兼容 DSH `>=0.2.1-rc.3 <0.3.0`。附带 `dsh-strong-skills-0.6.0.tgz` 安装包和 `SHA256SUMS.txt` 校验文件。
