# Strong Skills 0.4.4-preview.1 预览版

> 0.4.4-preview.1 收尾安全审计，修复审查发现的越权、数据丢失、正则挂起与命令注入问题；把 `strong_browse` 从“只能看文本”扩展为可查看页面、读取元素坐标并发送真实鼠标事件；新增默认关闭的 Windows 桌面工具 `strong_desktop`。按需技能从 8 个增至 11 个。

0.4.4-preview.1 是 0.4.4 线的第一个预览版，保留 0.4.3 的 Shell 沙箱、内置 Bash 与提示词压缩。默认仍是 6 个工具入口；开启 Shell 后 7 个，开启桌面工具后 7 个，两者同时开启为 8 个。升级不需要迁移 profile。

### 安全审计收尾

- **工作区逃逸**：realpath 缓存只保存成功结果，所有变更操作在前后清空缓存，阻断“预热 → 删除 → junction 交换”投毒链；路径解析不再对缺失分量回退纯词法检查，而是向上找到最近存在的祖先并校验真实路径，越界祖先立即拒绝。
- **命令执行边界**：Git 与 `taskkill` 只从工作区外的可信绝对路径启动，并显式设置工作目录；cmd.exe 参数改用严格允许列表与 cmd 风格引号；同步 coreutils 恢复 deadline 检查；函数递归限制 256 层；子 shell 的 `exit` 只结束子 shell；`cd` 同步宿主工作目录；`exec >file` 在脚本结束时正确落盘。
- **正则与资源上限**：安全扫描器识别非捕获组、连续量词与嵌套量词；`grep` 的 `a**` 折叠为 `a*`；`[[ =~ ]]`、`[[ == ]]` glob、参数替换与 awk 多字符 `FS` 不再直接构造可回溯正则；glob 与参数替换改为有界匹配；awk/printf/nl 宽度与精度设上限；`sort` 改为可中断归并；`tr` 范围受限；`ls -R` 与递归 `grep` 检测符号链接环。
- **文件语义与数据安全**：`mv` 遇到已存在目标目录时合并而不是递归删除，`ln` 拒绝覆盖真实目录；`cp` 的 `-L/-P/-p/-u/-a` 生效；`touch -d/-t/-r` 可用；`stat` 补回 `mtime/ino/dev`，`test -nt/-ot/-ef` 恢复；`ls -l`/readlink 不再泄漏宿主绝对路径。
- **联网边界**：`strong_web` 先解析并固定公网 IP 再连接，重定向逐跳复检，DNS 失败不再被吞掉，补 `198.18.0.0/15` 与 NAT64 黑名单；未闭合的 script/style/noscript/svg 不再把内容泄漏进正文。

### 浏览器真实交互

`strong_browse` 的 `open` 在导航前执行 SSRF 检查，浏览器启动时启用 CDP `Fetch`，对每个 HTTP(S) 子请求复用同一套公网地址校验；被拒绝的请求直接失败，不会继续加载。

新增与调整的动作：

- `view`：一次返回页面正文、最多 40 个可交互元素（标签、文本、id/name/type/href 与屏幕坐标）和 JPEG 截图。
- `click` / `hover` / `drag` / `mouse`：通过 CDP `Input.dispatchMouseEvent` 在元素中心或指定坐标发送真实鼠标事件，支持左/右/中键与 1–3 次点击；不再调用 DOM `el.click()`。
- `scroll`：使用真实 `mouseWheel` 事件。
- `snapshot` / `screenshot` 保留；截图可通过 MCP 作为 image content 返回。

提示词要求先 `open`，再 `view` 定位元素或坐标，操作后再次 `view` 验证；页面内容与坐标都按外部数据对待。

### Windows 桌面自动化（默认关闭）

`strong_desktop` 只在 `toolSet: expanded` 且 `desktopTool: true` 时注册。开启后，它通过常驻 PowerShell 5.1 主机编译一个小型 C# 助手，并串行处理 JSON 请求：

- `screenshot`：全屏 JPEG，可通过 MCP 返回 image content。
- `windows` / `activate` / `minimize` / `maximize` / `restore` / `close`：枚举与操作本机可见窗口。
- `move` / `click` / `drag` / `scroll`：`SendInput` + `SetCursorPos` 的真实鼠标，支持左右中键、拖拽与滚轮。
- `type` / `press`：Unicode 文本与组合键，作用于当前前台窗口。
- `launch` / `wait`：启动本机程序；等待指定毫秒，可被调用方取消。

坐标是**物理像素**，不是 CSS 像素；键盘输入进入当前前台窗口。桌面操作可能不可逆，使用前应先截图/枚举窗口定位，确认目标后再操作。

### 提示词与技能

- 常驻策略新增桌面路由：全局鼠标、键盘、窗口和软件操作使用 `strong_desktop`，先定位、再操作、再截图验证。
- 浏览器路由强调 `open → view → 真实鼠标 → view 验证`。
- 新增 `browser-automation`、`desktop-automation` 与 `shell-safety` 三个按需技能；技能目录为 11 个，单次加载上限仍由 profile 决定。
- MCP `initialize` 的 instructions、工具描述和原生配置开关同步更新。

### 兼容与边界

- 默认 6 个入口、四档预算与既有配置字段不变；`strong_shell` 仍是可选第 7 个入口，`strong_desktop` 是另一个可选第 7 个入口。
- 桌面工具仅支持 Windows 交互式桌面会话，依赖 PowerShell 5.1；不能提升到管理员权限，不能操作 UAC/安全桌面。全屏截图会包含屏幕上的其他窗口。
- 独立 MCP 服务没有 DSH 会话沙箱；`--shell on` 与 `--desktop on` 都以当前用户权限运行，需要隔离时使用原生插件并保持工具关闭。
- 浏览器点击是尽力而为：覆盖层、跨域 iframe 或页面自身阻止合成事件时可能失败，应报告失败而不是盲目重复点击。
- 内置 Bash 仍是 POSIX 子集，不是完整 Bash；`find -exec`、后台作业控制与部分 gawk 扩展未实现。

### 安装与升级

桌面端「插件 → 添加插件」使用固定版本来源，安装后完全退出并重新打开 DSH：

```text
github:wemebabo57-a11y/dsh-mcp-strong-and-skills#0.4.4-preview.1
```

web profile：

```sh
dsh plugin --profile web add github:wemebabo57-a11y/dsh-mcp-strong-and-skills#0.4.4-preview.1
dsh --profile web
```

本机 desktop profile 的依赖继续保持浮动（不要加 `#tag`），这样 DSHMarket 会按默认分支 `package.json` 的版本发现更新。

需要 **Node.js 24.9+** 与 **DSH 0.2.1-rc.3 或同一兼容范围内的更新版本**。
