0.4.0 为 Strong Skills 加入可选的本地命令执行能力，让模型在可信项目里完成构建、测试、格式化与 Git 操作，同时保持默认关闭和原有轻量工具面。

### 本次更新

- **可选内置 Bash**：新增 `bashTool` 开关，默认关闭。开启后提供第 5 个工具 `strong_bash`，可执行非交互式 shell 命令，返回退出码、标准输出、错误输出、耗时及超时/截断状态。
- **全链路生效**：设置页「内置 Bash」、原生 Config、CLI `--bash on|off`、生成的 native/MCP patch 与独立 MCP 服务共用同一开关。关闭时工具不注册、不列出、不可调用；默认工具面仍是原来的 4 个。
- **边界与安全**：初始工作目录限定在工作区根目录或经过校验的相对 `cwd`，拒绝目录穿越、绝对路径与符号链接逃逸；只传入允许列表中的非敏感环境变量；stdout/stderr 各限制 64 KiB；默认超时 60 秒（可设 1–120 秒），取消时终止子进程树。命令仍以当前用户权限运行，并非操作系统级沙箱，shell 可访问当前用户有权访问的其他路径，请只在可信项目中开启。
- **CLI 与 MCP 诊断**：新增 `node bin/strong.mjs bash --root . --command "npm test" --bash on`，MCP 将 `strong_bash` 标记为非只读、可破坏、开放世界，便于客户端提示风险。
- 保留 0.3.1 的项目设定与按需知识库、0.3.0 的全模型引导、无限 token 模式及全部既有技能。

### 如何使用

在「设置 → Strong Skills 编程增强 → 工具集」下打开「内置 Bash」，下一次请求即可看到 `strong_bash`。设置页会显示持续警告；关闭开关后工具立即从发现与执行中移除。

MCP 用户可在启动命令追加：

```sh
node bin/strong.mjs serve --root /absolute/path/to/project --bash on
```

### 安装与升级

桌面端进入「插件 → 添加插件」，使用下面的固定版本来源，安装完成后完全退出并重新打开 DSH：

```text
github:wemebabo57-a11y/dsh-mcp-strong-and-skills#0.4.0
```

web profile 可在终端安装：

```sh
dsh plugin --profile web add github:wemebabo57-a11y/dsh-mcp-strong-and-skills#0.4.0
dsh --profile web
```

需要 Node.js 24.9+；原生插件兼容 DSH `>=0.2.1-rc.3 <0.3.0`。附带 `dsh-strong-skills-0.4.0.tgz` 安装包和 SHA-256 校验文件。
